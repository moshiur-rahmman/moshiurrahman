# Moshiur Rahman — FMCG Sales Portfolio

A responsive, static personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — all website sections and text
- `style.css` — responsive design and styling
- `script.js` — mobile navigation and current year
- `assets/mr-logo.png` — uploaded MR logo
- `assets/Moshiur-Rahman-Public-CV.pdf` — public-safe CV generated from the uploaded CV

## Before publishing
1. Replace the hero's portrait placeholder with your own photo. Recommended: add `assets/moshiur-portrait.jpg`, then replace the placeholder block in `index.html` with an image using that path.
2. Replace the three gallery placeholders with real photos. Do not publish confidential company or distributor information.
3. Review the public CV and confirm every detail before publishing.
4. Test the Download My CV buttons after hosting.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new public repository, for example `moshiur-sales-portfolio`.
2. Upload the contents of this folder (not the ZIP itself) to the repository root.
3. Open **Settings → Pages**.
4. Under build/deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for the published URL shown in the Pages settings. Open it on desktop and phone and test all links.

## Publish with Netlify
1. Sign in to Netlify.
2. Choose **Add new site → Deploy manually** (wording may vary).
3. Drag the extracted project folder into the deployment area.
4. Open the generated site URL and test the CV download and navigation.

## Editing
- Change content directly in `index.html`.
- Update design colors near the top of `style.css` in `:root`.
- Keep the PDF at `assets/Moshiur-Rahman-Public-CV.pdf` or update both download links if you rename it.
- The original CV is not included in this package. The public-safe CV omits the passport number and referee phone numbers.

## Accuracy notes
The metrics and dates on the site follow the supplied CV. The 12% market-share gain is described as reported in the CV, not independently audited. Verify the CV's employment dates and performance figures before sharing with recruiters.
